## Deskripsi Program

Program ini dibuat untuk membantu pengelolaan pemesanan tiket kereta. Program menyediakan fitur menambah data, menampilkan data, mencari data menggunakan Linear Search, mengurutkan data menggunakan Bubble Sort, mengubah data, dan menghapus data.

## Fitur Program

* Tambah Data Tiket
* Tampilkan Data Tiket
* Cari Data Tiket (Linear Search)
* Urutkan Data Tiket (Bubble Sort)
* Edit Data Tiket
* Hapus Data Tiket
